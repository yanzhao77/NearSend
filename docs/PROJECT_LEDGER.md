## 1. 状态口径

- 已完成：限定范围内已有文件及可核对证据，不自动等于产品功能完成。
- 部分完成：某一参考层通过，仍有明确退出门槛。
- 阻塞：缺必要环境/设备，未执行，不计为通过或失败。
- 待开始：尚无该产品模块实现。
- 待复核：需要人工或独立实现验证，不用同一参考代码的自测替代。

不计算没有依据的整体完成百分比，不将Linux实验或HTTP loopback称为跨平台验收。
