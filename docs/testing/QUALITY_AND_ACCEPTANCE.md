# NearSend 质量与验收策略

## 1. 质量目标

质量优先级依次为：不损坏数据、不越权、不假完成、可恢复、可诊断、性能、视觉细节。吞吐量优化不得绕过持久化和校验。

## 2. 测试层级

| 层级 | 覆盖 | 运行频率 |
| --- | --- | --- |
| 静态门禁 | 格式化、分析、依赖/密钥/链接检查 | 每个 PR |
| 单元测试 | canonical 编码、状态机、空间算法、错误映射 | 每个 PR |
| 组件测试 | SQLite repository、文件适配器、API handler、Widget | 每个 PR |
| 协议契约 | 固定向量、未知字段、版本协商、错误码 | 每个协议变更及 PR |
| 集成测试 | client/server/存储完整路径、故障注入 | 每个相关 PR/夜间 |
| 平台真机 | 网络绑定、权限、生命周期、存储、热点 | 里程碑与发布候选 |
| 端到端验收 | 用户旅程、安装升级、实际大文件 | 发布候选 |

## 3. 必测矩阵

### 数据形态

- 0 B、1 B、块大小减 1、恰好一块、块大小加 1。
- 超过 4 GiB 偏移，1 GiB 和 20 GiB 真实落盘样本。
- 100 空文件、1,000 和 10,000 小文件、混合大小队列。
- Unicode、组合字符、同名、超长名、保留名、目录穿越输入。

### 网络与生命周期

- 同一 Wi-Fi；无上游互联网；Android 热点。
- 网络瞬断、切换网卡、热点重建、IP/端口变化。
- 前后台、锁屏、进程被杀、设备重启、发送端先恢复/接收端先恢复。
- 慢发送端、慢接收盘、高延迟、丢包和重复请求。

### 存储与恢复

- 块写入前、写入中、sync 前、sync 后/DB 提交前、DB 提交后崩溃。
- 磁盘满、权限撤销、外接盘拔出、导出失败、清理失败。
- committed 块损坏、暂存缺失、源文件变化、旧 `lease_epoch` 写入。
- 重复 Accept/Resume/Complete 请求和并发恢复。

### 安全

- 错误/变化的 TLS 指纹、过期/重复/错误方向令牌。
- 越权 task/file/chunk、越界 offset/length、摘要不匹配。
- 绝对路径、`..`、非法 Unicode、符号链接/重解析点逃逸（适用平台）。
- 日志、崩溃报告、截图和诊断包无密钥与完整令牌。

## 4. 设备证据

每次真机运行记录：运行 ID、日期、Git SHA、应用/协议/schema 版本、两端设备和系统、网络角色/频段/距离、源/目标存储、数据集、操作步骤、期望、实际结果、原始日志与截图/视频、结论和限制。

证据放入 `docs/testing/evidence/<date>/<run-id>/`。失败证据不得覆盖；修复后新增运行并互相引用。

## 5. 性能口径

性能报告必须分阶段：准备、连接、网络传输、终检、导出和端到端。至少报告有效载荷吞吐量、重传量、峰值 RSS、CPU、磁盘额外占用和能耗观察条件。

在目标设备基线形成前不冻结宣传数字。发布门槛需基于固定设备矩阵确定；Linux 参考实验不能替代 Android/Windows/iOS 产品性能。

## 6. UI 验收

使用真实状态注入或集成测试覆盖：准备、等待确认、传输、暂停、恢复校验、最终校验、保存、完成、部分失败、空间未知/不足、安全停止。禁止仅用 happy-path 截图表示 UI 完成。

检查手机窄屏、动态字体、深色模式、Windows 小/大窗口、键盘焦点、屏幕阅读器语义和 10,000 项列表性能。

## 7. CI 建议门禁

工程创建后至少建立：

```text
format → analyze → unit/widget tests → protocol vectors → integration smoke
       → dependency/security scan → build Android/Windows artifacts
```

平台签名发布作业与普通 PR 构建隔离，密钥只存在受保护环境。真机测试可在受控 runner 运行并上传证据索引，但结果必须关联准确 Git SHA。

## 8. 完成定义

任务标记完成需同时满足：实现与任务范围一致、代码已审阅、适用自动化测试通过、所需真机证据存在、文档/迁移同步、台账更新、已知风险明确。某项不适用要写原因；“没有环境”表示阻塞或待验证，不表示通过。

## 9. 发布阻断项

以下任一存在时不得发布：

- 内容损坏、整文件摘要不一致仍显示完成。
- 未验证身份即可提交凭证或访问任务文件。
- checkpoint 假提交导致恢复漏块。
- 取消/清理删除已导出或任务外文件。
- schema 迁移失败破坏旧任务且不可恢复。
- 承诺的无互联网模式在目标设备无法连接。
- 严重错误无可恢复路径且会丢失用户已接收数据。

## 10. 当前限制

仓库目前只有 Linux 参考探针和历史证据，没有 Flutter 产品、平台工程或三端真机结果。本文件定义未来验收标准，不改变台账中的现状判断。
