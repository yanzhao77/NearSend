# NearSend UI 样式指南

版本：UI Baseline 1.0。目标平台：Android、Windows、iOS。实现技术：Flutter Material 3，保留平台适配。

## 1. 品牌方向

NearSend 是可靠的本地传输工具，不是社交或云盘产品。视觉关键词：**直接、可信、安静、可恢复**。

- 主色使用清晰的蓝色，表达连接和行动。
- 成功绿色只用于“已校验并保存”，不能用于仅传输结束。
- 警告橙色用于空间未知、连接波动和可恢复风险。
- 红色用于身份异常、完整性失败、不可继续和危险删除。
- 大面积背景保持中性，让文件、设备和进度成为信息焦点。

### 2.2 排版

使用平台系统字体。中文优先 `PingFang SC / Microsoft YaHei / Noto Sans CJK SC`，由系统回退决定，不在安装包内重复嵌入大字体。

| Token | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display.large` | 32/40 | 700 | 关键进度、完成结果 |
| `title.large` | 24/32 | 700 | 页面标题 |
| `title.medium` | 18/26 | 600 | 卡片标题、分区标题 |
| `body.large` | 16/24 | 400 | 主正文、表单值 |
| `body.medium` | 14/22 | 400 | 默认正文 |
| `label.large` | 14/20 | 600 | 按钮、导航 |
| `label.small` | 12/18 | 500 | 标签、时间、错误码 |

动态字体放大至 200% 时，主操作、状态和错误原因不得截断。

### 2.3 间距与尺寸

- 基础网格：4px。
- 间距：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。
- 手机页面水平边距：20px；紧凑设备最低 16px。
- Windows 页面外边距：24–32px。
- 触控目标：至少 48×48dp。
- 默认按钮高度：48dp；紧凑桌面按钮最低 40dp。
- 输入框高度：48dp。
- 卡片内边距：16或20dp。
- 卡片圆角：16dp；按钮圆角：12dp；输入框圆角：12dp；状态胶囊：999dp。
- 边框：1dp；焦点环：2dp，外扩2dp。
- 阴影仅用于弹层和悬浮元素；普通卡片使用边框区分。

## 3. 图标与品牌标识

- 使用统一线性图标，默认 24dp、2dp 描边、圆角端点。
- “发送”使用向右上箭头，“接收”使用向下箭头；同时保留文字。
- 安全连接使用盾牌，不用锁图标暗示文件本身被长期加密存储。
- 完成使用带圆圈对勾，仅在终检和导出提交后出现。
- 产品标识建议为两个相向的圆角箭头围合成连接符号，保持单色可识别。

## 4. 组件规格

### 4.1 按钮

| 变体 | 场景 | 规则 |
| --- | --- | --- |
| Primary | 每页唯一主要动作 | 蓝底白字；loading时保留宽度 |
| Secondary | 更换位置、查看文件 | 浅底或描边，不争夺主操作 |
| Ghost | 工具栏、轻量导航 | hover/focus必须可见 |
| Danger | 取消任务、清理恢复数据 | 红色；破坏性动作需要确认 |

按钮状态：default、hover、focus、pressed、disabled、loading。加载状态不使用无限增长的假进度。

### 4.2 任务卡

固定信息层级：任务名称 → 对端设备 → 阶段/风险 → 进度或结果 → 下一动作。活动卡左侧可显示真实进度环；暂停、错误、完成使用图标和文字双重表达。

### 4.3 阶段进度

阶段固定为：准备、连接、传输、校验、保存。恢复时在传输前插入“检查本地内容”。已完成阶段使用对勾，当前阶段使用蓝色实心点，未开始使用灰色空心点；安全停止使用红色错误图标。

### 4.4 文件行

显示文件图标、可省略的文件名、大小、状态和可选操作。文件名中间省略以保留扩展名；悬停/长按可查看完整名称。10,000项列表必须虚拟化。

### 4.5 信息横幅

- Info：蓝色，解释连接或后台行为。
- Warning：橙色，空间未知或可能中断。
- Error：红色，身份、完整性或不可继续。
- Success：绿色，只用于最终成功或明确已完成子结果。

横幅结构：图标、标题、说明、最多两个动作、可选错误码。

## 5. 页面栅格

### 手机

- 单栏，内容宽度占满。
- 顶部AppBar 56dp；底部主操作在需要时固定，避开系统安全区。
- 长清单和说明滚动，主操作不能覆盖最后一项。

### Windows

- 侧栏 240px；紧凑窗口折叠为72px图标栏。
- 主内容最大宽度 1180px，列表与详情使用 `360px + flexible` 双栏。
- 最小支持窗口 900×640；低于阈值切为单栏详情导航。
- 所有交互提供键盘焦点、Enter/Space激活和Escape关闭弹层。

## 6. 动效

- 状态切换：180ms，标准缓动。
- 页面进入：200–240ms，轻微淡入/位移。
- 进度显示采样后的真实变化，不用循环动画伪造传输增长。
- 扫描总量未知时使用不确定进度；一旦总量确定切换为确定进度。
- 尊重系统减少动态效果设置。

## 7. Flutter命名建议

```text
NearSendTheme
NearSendColors
NearSendSpacing
NearSendTypography
NsPrimaryButton
NsStageProgress
NsTaskCard
NsFileRow
NsStatusBadge
NsInfoBanner
NsSpaceBreakdown
NsEmptyState
NsErrorState
```

组件接收领域枚举和格式化后的展示模型，不接收任意颜色或原生异常字符串。组件测试必须覆盖所有语义状态、深色模式、动态字体和窄宽布局。

## 8. 实现不可变项

- 不用单一百分比代替多阶段状态。
- 不在校验或保存阶段继续显示网络速度。
- 空间未知不能显示绿色通过。
- “已完成”只在文件终检和导出提交成功后出现。
- 取消确认必须说明已保存文件不会删除、未完成恢复数据会发生什么。
- 身份变化和完整性失败使用阻断式错误，不提供“忽略并继续”。
