# T12-03 响应式应用壳与真实数据读模型

状态：**就绪**
依赖：T12-01、T12-02、T12-00
依据：`docs/ui/UI_UX_SPEC.md` §2、§8、`AGENTS.md` §4–§5

## 目标

建立移动端/桌面端应用壳，并为任务、空间、设置页面接入真实数据边界。

## 退出门槛

- [ ] 手机 AppBar/底部导航、Windows 侧栏和窄窗口单栏布局可用。
- [ ] 任务读取只使用 SQLite 状态和 committed 块记录。
- [ ] 空间能力无法测量时保持 unknown。
- [ ] 非机密设置有迁移和测试；不存凭证、私钥和恢复密钥。
- [ ] 首页、任务、空间、设置路由存在且不破坏现有发送/接收路由。

## 人工重点复核

SQLite schema 迁移、任务恢复依据、平台句柄和设置隐私边界。
