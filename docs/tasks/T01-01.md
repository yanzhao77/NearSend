## 目标

建立一个可构建、可测试、版本可追踪的 Flutter 工程骨架：Android、Windows 与 iOS 三端平台目录齐备，Android 与 Windows 能构建并运行同一个壳应用；应用能如实显示应用版本、Git commit、协议版本和数据库 schema 版本。

本任务只交付**工程基线与可追踪性**，不交付任何传输、配对、存储或空间功能。

## 范围内

- 由 `flutter create` 生成规范的 Flutter 工程，平台集合固定为 `android`、`windows`、`ios`。
- 按 `AGENTS.md` §4 与 `APP_AND_SERVICE_DESIGN.md` §2 建立 `lib/app`、`lib/core`、`lib/features`、`lib/platform` 的真实文件（不建空目录、不放占位文件）。
- `lib/app/theme/design_tokens.dart`：逐值实现 `UI_UX_SPEC` §5 的颜色、间距、圆角、字号、动效与可访问性 Token。
- `lib/core/build_info/build_info.dart`：应用版本、协议版本、数据库 schema 版本、Git 提交的**单一权威常量**。
- 首页壳：符合 `UI_UX_SPEC` §4 的信息架构与空态文案；未实现的主操作必须显式禁用并标注所属后续任务。
- 版本信息页：展示应用版本、Git commit、协议版本、数据库 schema 版本、构建渠道。
- 平台目录只做资源与标识适配（应用显示名、窗口标题），不含业务逻辑。
- `tooling/scripts/` 下的检查与构建脚本，注入 Git 提交并输出产物摘要。
- 单元测试与 Widget 测试覆盖上述内容。
- `docs/tasks/`、`docs/decisions/ADR-0001`、证据与台账更新。

## 范围外

- 传输、配对、发现、TLS、SQLite、空间计算、导出、恢复等任何业务功能。
- UI/UX 规范中除首页与版本信息页以外的页面（禁止预先生成静态页面壳）。
- 正式签名材料、渠道包、Google Play / App Store / MSIX 发布（T10）。
- CI 流水线（T01-02）、协议模型（T02-01/T02-02）、SQLite schema（T04-01）。
- 冻结最低 Android SDK 版本、TLS 引擎、SQLite 插件、Windows 最低系统版本（保留为待冻结项）。

## 接口与不变量

- `kAppVersion`、`kProtocolMajor`、`kProtocolMinor`、`kDbSchemaVersion` 各自只有一个定义处；其它层只能消费，不得重复定义。
- `kAppVersion` 必须与 `pubspec.yaml` 的 `version` 一致，并由自动化测试保证。
- `pubspec.lock` 必须被 Git 跟踪（`AGENTS.md` §3「依赖锁定」）。
- 协议版本常量在 T02-02 冻结前必须显式标注为草案，不得表述为已冻结。
- 数据库 schema 常量在 T04-01 落地前只表示「已声明版本号」，不得表述为「数据库已创建」。
- Git 提交通过构建期 `--dart-define` 注入，缺失时显示 `unknown`，不得显示伪造的 SHA。
- 平台目录（`android/`、`windows/`、`ios/`）相对生成基线的差异只允许是标识类资源改动，不允许业务逻辑。
- 应用不引入未经验证的第三方运行时依赖。

## 基线变化并入：UI Baseline 1.0

本任务进行期间，`docs/ui/STYLE_GUIDE.md`（UI Baseline 1.0）经 PR #3 合并进 `master`，
成为视觉权威（`docs/ui/UI_UX_SPEC.md` §5 也已改为指向它）。该指南比 UI_UX_SPEC §5 更精确，
且在两处推翻了原实现采用的数值：

| 项 | 原实现（UI_UX_SPEC §5） | UI Baseline 1.0 |
| --- | --- | --- |
| 卡片圆角 | 12 | **16** |
| 按钮圆角 | 10 | **12** |
| 页面背景 | 与卡片同为 `surface` | **独立 `canvas` 色**（Light `#F8FAFC` / Dark `#0B1220`） |
| 颜色 Token 数 | 9 | **17**（新增 hover/soft/canvas/border/muted 与三个语义 soft 背景） |

因此 `lib/app/theme/design_tokens.dart` 已按 UI Baseline 1.0 重写，`NearSendPalette` 更名为
`NearSendColors`（对齐指南 §7 的命名建议），测试逐值断言并新增 `canvas`/`card` 区分、
卡片 1dp 边框、语义色与其 soft 背景的 WCAG AA 对比度等检查。测试总数由 29 增至 36。

按 `AGENTS.md`「合并前处理基线变化并重新运行相关检查」的要求，`origin/master` 已并入本分支，
`docs/PROJECT_LEDGER.md` 的 §7 冲突已人工解决（两侧变更均保留），随后完整重跑格式、分析、
