# T12-06 发送流程页面

状态：**待验证**
依赖：T12-02、T12-03
依据：`docs/ui/UI_UX_SPEC.md` §4–§6；`AGENTS.md` §2

## 目标

重做文件选择、准备/扫描、发送状态和失败重试视觉。

## 退出门槛

- [x] 文件数、总大小、文件行、来源错误和重复名可读。
- [x] 准备进度真实；不把网络写入量当作恢复依据。
- [x] 准备、等待、传输、校验、保存状态区分。
- [x] Android SAF 与 Windows 路径输入差异保留。

## 人工重点复核

大文件流式准备、真实进度、长文件名和一万项列表。

## 实现记录

- 发送页使用 `NsFileRow`、`NsInfoBanner`、`NsPrimaryButton` 和 `NsSecondaryButton`。
- 文件名采用中间省略并保留末级扩展名，完整名称通过 Tooltip 保留；文件清单使用 `ListView.builder`，避免一次性展开所有行。
- 页面固定展示准备、连接、传输、校验、保存五阶段；速度和剩余时间只在真实发送阶段显示。
- 文件来源异常和发送失败使用共享语义横幅，路径平台仍显示路径输入，文档平台仍显示文件选择入口。
- 定向组件和发送页测试已通过；Flutter analyze 与目标平台构建仍受当前 SDK/环境限制。
