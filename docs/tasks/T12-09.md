# T12-09 Android、Windows、iOS 平台适配

状态：**阻塞**
依赖：T12-00 至 T12-08
依据：`AGENTS.md` §3、§4、§7；T12-00 探针记录

## 目标

完成平台布局、文件资源、目录、空间和键盘/生命周期适配。

## 当前实现

- Android 新增平台存储网关：默认接收位置使用应用私有 `filesDir/received`，可用空间通过原生 `StatFs` 测量并返回 `StorageMeasurement`。
- Android 的 SAF 文件选择和有界读取/写入通道继续由 `MainActivity` 负责；无效或不可测量的位置保持 `unknown`。
- Flutter 主入口仅在 Android 装配该网关；Windows、iOS 未验证时继续使用未知能力，不显示假空间通过或不可写目录选择。
- 目录选择入口由 `supportsDirectorySelection` 控制。当前导出器仍要求普通路径，因此 Android SAF tree URI 选择暂不开放，避免返回无法写入的引用。
- 桌面应用壳加入阅读顺序焦点遍历；Windows 原生窗口限制为不低于 `900×640`，与 UI 单栏阈值一致。
- iOS 增加本地网络权限说明；安全作用域目录、空间测量和生命周期仍需 Xcode/真机验证。
