# T12-04 首页与关于页

状态：**待验证**
依赖：T12-02、T12-03
依据：`docs/ui/UI_UX_SPEC.md` §4

## 目标

按 UI 基线重做首页、最近任务/继续入口和关于诊断页。

## 退出门槛

- [ ] 发送/接收等权重。
- [ ] 继续任务只在真实可恢复任务存在时出现。
- [ ] 本地 Wi-Fi 和无互联网说明清晰。
- [ ] 关于页保留版本、协议、schema、Git 和构建渠道的真实状态。

## 人工重点复核

不能把工程壳、未知空间或未验证平台显示成完整产品能力。

## 实现记录

- 首页显示真实设备名、节点状态、本地 Wi-Fi 说明和条件式可恢复任务入口。
- 关于页保留版本、Git、协议、schema、构建渠道，并增加安全诊断和平台验证边界说明。
- 页面测试和已有应用级连接/发送/接收测试已通过。
