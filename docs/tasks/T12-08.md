# T12-08 任务详情、传输详情与结果

状态：**待验证**
依赖：T12-02、T12-04、T12-06、T12-07
依据：`docs/ui/UI_UX_SPEC.md` §4–§6；`lib/features/transfer/presentation/transfer_progress.dart`

## 目标

统一五阶段进度、暂停/恢复、断线、部分失败、完整性失败、保存失败和最终结果。

## 退出门槛

- [x] 任务列表和详情使用真实 SQLite 状态、committed 块和导出记录。
- [x] 五阶段进度固定为准备、连接、传输、校验、保存。
- [x] 完成只在任务状态为 `completed` 且文件有已保存导出记录时显示成功语义。
- [x] 取消确认解释已保存文件不会删除，以及未完成恢复数据的影响。
- [x] 可恢复、部分失败、完整性/保存失败和暂停状态使用不同语义。
- [x] 暂停、继续、取消、重连和仅重试失败项只有在调用方提供真实能力时才渲染。

## 当前实现

- `TaskCatalogController.detail()` 从 SQLite 读取任务文件、每个文件的 committed 块字节、文件状态和导出记录。
- 新增 `TaskDetailPage`，任务列表卡片可进入详情；没有数据库任务记录时显示诚实错误空态。
- 详情页使用共享阶段进度、文件行、状态横幅和语义状态徽章；已完成任务显示保存记录，失败任务不使用成功样式。
- 当前协议仍未定义失败文件的恢复出边，因此 UI 不伪造“重试”能力；仅当真实回调接入时才展示该动作。
