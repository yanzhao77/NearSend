# T12-02 共享 UI 组件

状态：**就绪**
依赖：T12-01
依据：`docs/ui/STYLE_GUIDE.md` §4、§7；`docs/ui/UI_UX_SPEC.md` §6

## 目标

在 `lib/app/widgets/` 建立按钮、Banner、状态、文件、阶段、空间、任务和空态组件。

## 退出门槛

- [ ] 组件接收领域状态/展示模型，不接收任意语义颜色。
- [ ] 覆盖 default、hover、focus、pressed、disabled、loading、Light/Dark、长文案和窄屏。
- [ ] 组件 Widget 测试通过。

## 人工重点复核

按钮破坏性动作、状态图标与文字双重表达、屏幕阅读器标签。
