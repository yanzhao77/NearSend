# T12-05 配对与连接页

状态：**待验证**
依赖：T12-02、T12-03
依据：`docs/ui/UI_UX_SPEC.md` §4；`AGENTS.md` §5

## 目标

统一发现、指纹验证、连接、失败、会话过期和节点不可用的视觉状态。

## 退出门槛

- [x] 保留严格 PairingPayload 解析和 TLS pin 校验。
- [x] 指纹变化阻断连接并要求重新配对。
- [x] 错误状态提供下一步。
- [x] 不引入全局信任、明文降级或未经验证的 QR 依赖。

## 人工重点复核

证书指纹、一次性令牌和重新配对路径。

## 实现记录

- 连接页展示本机/对端设备名、平台、地址和指纹状态；协议未提供的对端元数据保持明确未知。
- 指纹验证前使用“待验证”警告状态，连接成功后才显示“已验证”；指纹不匹配仍阻断并显示对端实际指纹。
- 连接失败、节点启动失败和会话未建立均使用共享信息横幅提供原因，不改变既有严格解析和 TLS pin 行为。
- 未引入 QR 或其他第三方依赖。
- 定向测试已通过；Windows/iOS 真机和 Flutter analyze 因当前环境限制仍待验证。
